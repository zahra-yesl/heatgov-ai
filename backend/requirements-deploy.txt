# HeatGov AI - runtime-only dependencies for a hosted deployment.
#
# WHEN TO USE THIS FILE
#
# `requirements.txt` is the development environment: it installs JupyterLab,
# ipykernel, Folium and pytest, none of which the running API imports. On a
# 512 MB free-tier instance that install is slow and the extra packages buy
# nothing, so point the build command here instead:
#
#     buildCommand: pip install -r backend/requirements-deploy.txt
#
# See docs/DEPLOYMENT.md.
#
# The versions are copied from requirements.txt and must stay in step with it.
# The pins are explained there; the short version is that they are chosen for
# Windows Smart App Control and for two library incompatibilities
# (numba <= 0.60 needs numpy < 2.1; shap 0.46 cannot read xgboost >= 3.0
# models). Keeping the same pins here means the deployed API runs the exact
# model artifacts that were trained locally.
