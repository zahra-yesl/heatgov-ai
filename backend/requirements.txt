# WHY THE STRICT PINS

# The development machine runs Windows 11 with Smart App Control ENFORCED.

# whose file hash has no established Microsoft reputation, which in practice
# means "very recently released wheels are blocked".
#
# The versions below were verified to (a) load under Smart App Control and
# (b) work together. Bumping any of them may reintroduce:
#   ImportError: DLL load failed ... An Application Control policy has blocked this file.
#
# Additional compatibility constraints baked into these pins:
#   * numba <= 0.60 requires numpy < 2.1        -> numpy is pinned to 2.0.2
#   * shap 0.46 cannot parse xgboost >= 3.0 models (base_score serialisation)
#                                               -> xgboost is pinned to 2.1.4
# ---------------------------------------------------------------------------
