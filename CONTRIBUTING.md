# Contributing

Thanks for looking at HeatGov AI. This was built for the FortyGuard Hackathon
2026; the notes below are what you need to get it running and to keep changes
consistent with the rest of the codebase.

## Getting set up

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
copy .env.example .env      # then fill in your keys - see SECURITY.md

cd frontend
npm install
```

Python **3.11** specifically. Several packages are pinned to older versions
because Windows Smart App Control blocks the newer compiled DLLs; the reasoning
is in [docs/environment-notes.md](docs/environment-notes.md) and the pins carry
comments in `backend/requirements.txt`. Please do not bump them casually.

## Running it

Two terminals:

```powershell
# API on port 8000
.\.venv\Scripts\python.exe -m uvicorn api.main:app --app-dir backend --port 8000

# interface on port 3000
cd frontend; npm run dev
```

## Running the tests

```powershell
.\.venv\Scripts\python.exe -m pytest backend\optimizer\ -v     # 14 unit tests
.\.venv\Scripts\python.exe backend\api\test_endpoints.py       # 27 end-to-end checks
cd frontend; npm test                                          # 50 browser-path checks
```

The last two start real servers and make real HTTP requests; `npm test` also
makes one live Gemini call. Use `npm run test:no-agent` to skip it. Free the
port first — the API suite starts its own uvicorn on 8000 and will fail to bind
if one is already running.

## House style

**Language.** Everything in the repository is in American English: code,
comments, commit messages, UI text, documentation.

**Comments explain why, not what.** The code says what it does. A comment earns
its place by recording the thing the next reader cannot see — a constraint, a
measurement, a rejected alternative. Several comments in this codebase exist
because a plausible-looking approach was tried and failed; keep those.

**Never invent a number.** If a value is missing, the code says so and marks
the result provisional. `backend/agent/tools.py` and the
`canopy_data_available` flag are the pattern to follow.

**Report the honest score.** Cross-validated metrics with their spread, not a
single flattering split. `README.md` states where the models are weak, and that
section should grow rather than shrink.

## Data files

`data/raw/`, `data/processed/`, `data/external/` and `models/` are git-ignored.
Cached API responses and trained models are regenerated by running the
pipeline; external datasets are downloaded by hand following
[data/external/README.md](data/external/README.md). Please do not commit them —
they are large, and the FortyGuard cache is tied to a specific account.

## Pull requests

Before opening one:

- `npx tsc --noEmit` and `npx eslint .` pass in `frontend/`
- the three test suites above pass
- no key, token or `.env` file is in the diff

Describe what you measured, not only what you changed.
